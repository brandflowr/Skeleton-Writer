# Skeleton Writer quick start

Writing is local. Genlock and an AI assistant are optional.

1. Choose a folder you own. New story starts a blank scene; short-film, episode, commercial and narrated-video starters include examples to replace.
2. In **Write**, choose prose or Fountain and write continuously. Use **Structure** for the scene location and detailed shot fields; shots can stay empty. Fountain supports character cues, dialogue, parentheticals and transitions. Ctrl+1/2/3/4 insert common elements.
3. Use **Outline** to change scene intent and order; **Bible** maintains character/location identities. **Map** tracks chronology and setup/payoff threads. A timing estimate is not a measured running time.
4. Ctrl+S saves. Autosave is enabled initially; turn it off when you want manual saves. Ctrl+Z and Ctrl+Shift+Z undo/redo document edits. An external disk change stops a save and offers comparison or a separate copy.
5. In **History**, name a snapshot before a major revision. Compare scene writing or the complete source. Recovery offers a timestamped draft after an interruption; review both versions before restoring. Work typed after the last completed checkpoint may not be recoverable.
6. **Review** adds quoted comments and previews an assistant-proposed SKEL draft. Selected existing-scene writing can be applied with undo; structural additions and deletions require separate review.
7. **Export** previews the selected content and explains losses. Keep SKEL for the whole project; use Fountain for screenplay interchange. DOCX, basic FDX and PDF support only their documented subsets, including sequential rather than simultaneous dual dialogue. PDF export stops if its font lacks a character.
8. A portable project includes only the story, media files you explicitly select, and optional research. Supply each supported referenced asset, review the list, and import into a fresh folder. The 64 MB limit applies to expanded contents.

Read-through uses installed local system voices and reports when none are available. Your chosen research text opens read-only beside the draft. Spellcheck availability depends on the native environment; custom dictionary acceptance is not yet established.

The assistant kit can be exported or installed separately. Installing a writing skill does not run it or send your draft. The external assistant owns generation; inspect its returned source and apply changes deliberately.

For Genlock, use the complete SKEL/JSON and its supported import route. Writer scene text can remain authoritative while production shots evolve separately. The new Genlock revision preview applies selected existing scene-writing changes to the production with a backup; end-to-end production acceptance remains pending. Do not treat a validated file as proof of a completed production transfer.
